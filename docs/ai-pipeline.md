# FloatChat AI Intelligence & Synthesis Pipeline

## 1. Pipeline Overview

The FloatChat AI layer bridges human curiosity with rigorous oceanographic data. It translates free-form natural language questions into validated search criteria, retrieves and filters ARGO float observations, and synthesizes scientifically accurate, grounded answers.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. User Natural Language Question                           │
│    "What is the salinity near Chennai at 100 meters?"       │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. Query Understanding (LLM / Deterministic)                │
│    - Extracts Intent: PROFILE_QUERY                         │
│    - Resolves Location: Chennai (13.0827°N, 80.2707°E)       │
│    - Resolves Parameter: PSAL (Practical Salinity)          │
│    - Resolves Depth: Target 100.0 meters                    │
│    - Validates bounds & confidence score                    │
└──────────────────────────────┬──────────────────────────────┘
                               │ Output: StructuredQuery
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. Geodesic Retrieval & QC Filter Engine                    │
│    - Calculates Great-Circle Haversine distances            │
│    - Selects nearest vertical level within tolerance        │
│    - Sanitizes bad QC flags (discards 4, 9)                 │
└──────────────────────────────┬──────────────────────────────┘
                               │ Output: Matched ArgoObservations
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. Pre-Computed Authoritative Statistics                    │
│    - Calculates pure-Python stats: mean, min, max, std      │
│    - Extracts active float WMO IDs & depth bounds           │
└──────────────────────────────┬──────────────────────────────┘
                               │ Output: DataSummary
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. Response Synthesis Layer                                 │
│    - Generates grounded Markdown narrative with context     │
│    - Builds ARGO float provenance citations                 │
│    - Formats frontend chart data points & map markers       │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. Output: FloatChatResponse                                │
│    - Conversational Answer + Citations + Charts + Maps      │
└─────────────────────────────────────────────────────────────┘
```

## 2. Intent Classification

FloatChat classifies incoming questions into one of six distinct intents:

1. **`profile_query`:** Depth profiles or measurements at specific vertical levels (e.g. *"Show temperature at 100m near Kochi"*).
2. **`spatial_query`:** Regional ocean condition queries (e.g. *"What are conditions across the Bay of Bengal?"*).
3. **`temporal_query`:** Time-series, monthly trends, or seasonal variations (e.g. *"How has temperature changed near Mumbai since last year?"*).
4. **`comparison_query`:** Comparative analysis between regions or depths (e.g. *"Compare salinity in the Arabian Sea and Bay of Bengal"*).
5. **`float_query`:** Specific float trajectories or sensor health by WMO ID (e.g. *"Show data from Float 2903334"*).
6. **`unknown`:** Out-of-domain or ambiguous queries, generating helpful guidance on supported oceanographic topics.

## 3. Physical Oceanography Grounding & Context

When explaining observations, FloatChat provides domain-accurate physical context:
- **Bay of Bengal Salinity Stratification:** Low-salinity surface waters from river runoff (Ganges/Brahmaputra) creating vertical salinity barrier layers that suppress ocean mixing.
- **Arabian Sea Water Masses:** High salinity (ASHSW) driven by intense net evaporation exceeding precipitation, coupled with Southwest Monsoon upwelling along the Malabar coast.
- **Thermocline Dynamics:** Explains sharp temperature gradients between warm mixed layers and colder deep water.
- **Oxygen Minimum Zones (OMZ):** Biological respiration and low ventilation creating intermediate oxygen minimums in the north Indian Ocean.

---

## 4. Frontend Visualization Contracts

Every response generated by `FloatChatAIEngine` includes structured payloads:
- **`citations`:** Verified WMO float IDs, cycle numbers, coordinates, timestamps, and geodesic distances.
- **`chart_data`:** Depth vs. parameter coordinate points sorted vertically for instant profile plotting.
- **`map_markers`:** Float coordinates and status summaries for interactive map rendering.
