# FloatChat Product Screenshots & Visual Assets

This directory contains visual captures and interface diagrams showcasing FloatChat's core product capabilities for hackathon judges and evaluators.

---

## Recommended Asset Layout

| File Name | Section | Description |
| :--- | :--- | :--- |
| `01-conversational-interface.png` | **Conversational Intelligence** | Natural language chat interface answering questions with grounded oceanographic data and citations. |
| `02-depth-profile-chart.png` | **Environmental Data Visualization** | Vertical profile chart rendering Depth vs. Salinity/Temperature across water layers. |
| `03-argo-float-map.png` | **Risk & Sensor Map** | Interactive geospatial map rendering active ARGO float platforms and trajectory points. |
| `04-climate-signals.png` | **Environmental Signals** | Ocean anomaly alerts, mixed layer depth indicators, and regional comparison cards. |
